The mark

A monogram in three strokes

My initials with the three letters—D, G, S—intertwined into one symbol based on my handwriting.

But I never write is quite the same way twice. Sometimes I like it more and other times less. I wanted a standardize form that I can use as a template.

Where it lives

I put it on the things I make

I engrave, carve, embroider, etch, or stamp it onto objects I make along with the year. That way I can see when I made it.

There is significant variation is how I write the monogram as a guide that is amplified as it is permantly added to the object by hand.

From hand to curve

Thirty-eight signatures, traced

To study the mark, I wrote it hundreds of times. I chose the few I liked—38 versions of the monogram. I scanned the pages in, created high contrast images of the marks I liked, and traced each one into the same three Bézier paths—the same strokes and control points, only with differing positions. That skeleton makes the samples comparable: every mark becomes the same 49 numbers, just with different values.

Each ink scan (left) traced to a clean vector (right). Same topology every time.

Manipulating the shapes

The eigenbasis of my mark

With every monogram converted to consistent Bézier paths, I ran a principal-component analysis of how the set differs from the mean shape. This gave eigenvectors of how my monograms deform from the mean. Rather than independently varying the control points, which results in unnatural shapes, I can use the eigendeformations to modify the shapes in ways that have more or less of different characteristics of how I write my maker's mark.

The first three eigenvectors account for about 63% of everything that differs between my monograms. Below, each bar is one eigendeformation's share of the variation.

The comparere

Deciding on the shape I like best
